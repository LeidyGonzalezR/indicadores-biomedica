Importar informes anteriores

Selecciona un informe institucional en Word (.docx) o PDF con texto seleccionable. Se recuperarán únicamente datos reconocibles; siempre podrás revisar las cantidades antes de guardarlas. No sustituye ningún registro existente.

La lectura de archivos requiere conexión a internet para cargar los componentes de lectura. Los PDF escaneados no tienen reconocimiento OCR en esta etapa. No se envían los documentos a OneDrive.

Revisión previa

Los campos vacíos necesitan confirmación. El botón de abajo traslada los datos al formulario mensual; no los guarda automáticamente.

Exportar informe de trabajo a Excel

Se generará un archivo .xlsx con hojas de resumen, datos mensuales, desglose de correctivos por servicio y gráficas de los indicadores del año.

El Excel contiene fórmulas de comprobación y conserva los datos originalmente registrados. La exportación requiere conexión a internet para cargar el generador de archivos Excel. Este no es el informe PDF institucional.

Informe institucional de indicadores

Genera el documento mensual con el encabezado de Mejoramiento Continuo, cuatro indicadores, gráficas históricas, desglose de correctivos por servicio, análisis y acciones de mejora.

El documento se abrirá en una ventana lista para imprimir. En el cuadro de impresión selecciona «Guardar como PDF». Esta versión reproduce los elementos institucionales esenciales del informe de septiembre; revisa la vista previa antes de entregarlo oficialmente.

Copias de seguridad locales

En esta primera etapa los registros permanecen únicamente en este navegador. Recomendamos descargar periódicamente una copia JSON y conservarla en una ubicación segura.

Importar una copia reemplazará el conjunto local de registros y servicios, previa confirmación. No equivale a sincronizar con OneDrive.
